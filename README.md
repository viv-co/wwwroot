### 製作你的無程式碼


在這 30 天


這次想挑戰的並不是使用 _no-code_ 平台實作一個網頁出來，而是自己手刻製作無程式碼的個人網頁。什麼意思？我會：

- 用 
- 串各種 API 顯示資料當網頁內容
- 部署！

那 _no-code_ 的點在哪呢？這網頁不需要更新或編輯，都會自動拿到最新資料，而且做完之後大家都可以拿來用做自己的個人網頁！所以 _no-code_ 是未來(開發完)的事，也是對其他人來說應該是 _no-code_ 沒錯 ＸＤ


對我開發者本人就是個有取好玩的東西～
